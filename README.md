# 🇹🇷 Türkçe (Turkish)

# The Brew Loft - Kurumsal Restoran Web Arayüzü

## Proje Hakkında
Yiyecek-içecek sektörü için tasarlanmış, modern UI/UX standartlarını (Kullanıcı Arayüzü / Kullanıcı Deneyimi) temel alan dinamik bir kurumsal web sitesi projesidir. Müşterilerin marka kimliğini dijitalde en iyi şekilde hissetmesi için görsel hiyerarşi ve hızlı erişim odaklı geliştirilmiştir.

## Temel Özellikler
* **Dinamik Medya Kaydırıcı (Carousel):** Ana sayfada öne çıkan ürünlerin akıcı bir görsel sunumla sergilenmesi.
* **Kategorize Edilmiş Dijital Menü:** Kullanıcıların ürünlere (Kahvaltı, Et, İçecek vb.) en kısa yoldan ulaşmasını sağlayan çok sayfalı (multi-page) temiz menü mimarisi.
* **Lokasyon ve Harita Entegrasyonu:** Müşterilerin işletmeyi kolayca bulabilmesi için Google Maps (Iframe) canlı harita modülü entegrasyonu.
* **Modern CSS Mimarisi:** Arayüz bileşenlerinin hizalanması ve konumlandırılması için gelişmiş CSS Flexbox ve CSS Grid yapıları kullanılmıştır.
* **Yapay Zeka Destekli JS Entegrasyonu:** Sitenin interaktif özellikleri (kaydırıcılar, buton geçişleri) modern prompt mühendisliği ve yapay zeka araçları yardımıyla kodlanmıştır.

## Geliştirme Yol Haritası (Future Updates)
* **Mobil Cihaz Optimizasyonu (Responsive Design):** Sitenin akıllı telefonlar ve tabletlerde kusursuz bir kullanıcı deneyimi sunması için mobil arayüz (responsive) uyumluluk çalışmaları ve optimizasyon süreçleri aktif olarak devam etmektedir.

# 🇬🇧 İngilizce (English)

# The Brew Loft - Corporate Restaurant Web Interface

## About the Project
A dynamic corporate website project designed for the food and beverage industry, built upon modern UI/UX standards. It focuses on visual hierarchy and quick accessibility to ensure customers experience the brand identity seamlessly in the digital environment.

## Key Features
* **Dynamic Media Carousel:** A fluid visual presentation showcasing featured products and atmosphere on the homepage.
* **Categorized Digital Menu:** A clean, multi-page menu architecture allowing users to easily navigate through product categories (Breakfast, Steaks, Beverages, etc.).
* **Location & Map Integration:** Live Google Maps (Iframe) integration so customers can easily find the physical establishment.
* **Modern CSS Architecture:** Advanced CSS Flexbox and CSS Grid layouts are utilized for precise alignment and positioning of UI components.
* **AI-Assisted JS Integration:** Interactive website features (carousels, button transitions) were developed using modern prompt engineering and AI tools.

## Development Roadmap (Future Updates)
* **Mobile Device Optimization (Responsive Design):** Mobile interface compatibility and layout optimization processes are actively ongoing to ensure a flawless user experience across all smartphones and tablets.
